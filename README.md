# Mi Proyecto

## Descripción

# Trabajo Práctico Intermedio para la UTN - Fullstack, Front-End

El objetivo de crear una web con los siguientes requisitos para poder entregar en la fecha estipudala (28/10/2026).

# OBJETIVOS

Construir un sitio web completo desde cero, aplicando todos los conceptos arquitectónicos y visuales que hemos aprendido en el Módulo 1 (HTML Semántico, Box Model, Flexbox y Diseño Responsivo).  

# Arquitectura del Proyecto 

/tu-proyecto 
│ 
├── /assets           
│   └── /img          
│ 
├── /css              
│   └── styles.css    # Archivo CSS global 
│
├── /Emulacion de Redes              
│   └──imagenes       # Imágenes que simulan una red social
│   └──*.html         # html para solo abrir como una red social  
│
├── index.html        # Web de inicio (home)
├── asesores.html     # Sección donde estan los asesores
├── experiencia.html  # Sección donde cuentan sus experiencias los clientes  
├── galeria.html      # Sección donde se muestran algunos destinos  
├── nosotros.html     # Sección donde la empresa expresa sus políticas  
└── contacto.html     # Sección donde el cliente se puede poner en contacto

# Tecnología usada

* HTML: Para maquetado de la web
* CSS: Para darle estilos visuales a la web en Escritorio y en Celular.
* ChatGPT: para consultas, soluciones, y armado de imágenes.
